# v0.1.3 — one version, fewer empty rows

Two small alignment fixes with the desktop.

## What changed

- **The footer shows the package version.** It used to append a hand-maintained
  build counter (`v38`), which drifted from `package.json` and said nothing
  about which release the phone was actually running. The gateway now injects
  `v` + `package.json.version` into the page, so the list and conversation
  footers read `v0.1.3` and a stale value means an old installed copy.
- **Blank Sessions are hidden like the desktop.** The phone listed every
  no-prompt draft as `(未命名)`, while the desktop keeps blank Sessions out of
  the tree unless they are the open draft. The list now drops a Session only
  when the controller positively reports `blank: true`; a missing cold summary
  never hides a real Session.

## Implementation notes

- `lib/page.html` contains `const VERSION = '__MOBI_VERSION__'`; `mobilePage()`
  replaces the placeholder per request from the package's `version`. No build
  counter to bump.
- `mobile.list()` filters `summary.blank === true` while building the grouped
  list, so the workspace counts and the "older" split stay consistent.
- 48 tests, including the served-page version and the blank-list filter.

## Upgrade

```bash
dsh plugin --profile desktop add dsh-mobi-web@0.1.3
# restart the app
```
