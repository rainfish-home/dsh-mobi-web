# v0.1.0 — first public release

A phone-first web client for DeepSeek Harness: a ~32 KB page that talks to the
harness in-process, so it stays usable over a relayed mobile link where the
official UI (4.6 MB of JS) spends ten seconds on a white screen.

## Highlights

- **32 KB page**, no framework, no CDN — Markdown, code blocks, tables and
  Mermaid diagrams rendered on the device.
- **Approvals stay on the phone.** If the turn was started from the phone, the
  approval waits there for up to 15 minutes and then *cancels*; it never falls
  back to a desktop nobody is sitting at. Desktop-origin turns keep the old
  behaviour (20 s grace, then hand back).
- **Live streaming** over SSE with backoff reconnect (2 s → 30 s) and a 6 s
  poll as fallback; history comes with the newest 40 messages / 120 k chars.
- **Send, don't just read**: multi-line text, up to 4 images per message,
  cancel a running turn, create a session in any workspace.
- **Sessions grouped by workspace**, newest first, active vs. older split at
  24 h, archived filtered out, collapse state remembered.
- **One token, one gate**: minted on first start into
  `$DSH_HOME/dsh-mobi-web-token` (mode 0600); `?t=` links are disabled on
  purpose, so a bookmarked URL never carries a secret.

## Install

```bash
# web or any npm-style profile
dsh plugin --profile web add dsh-mobi-web

# the desktop profile — `desktop` is reserved for the Electron-owned profile,
# so use the app's plugin manager or its bundled `dsh` command
dsh plugin --profile desktop add dsh-mobi-web
```

The plugin is a DSH bundle: it ships its own `cordis.patch.yml`, so no profile
file is edited by hand. Then point a tunnel at `127.0.0.1:3083` and open
`https://<host>/m/`.

## Security

The token is equivalent to access to the whole harness: prompts, tool
approvals (**including shell commands**) and every session on the machine. Put
it behind Tailscale rather than a public tunnel unless you know what you are
doing. Full text at the top of the README.

## Verified

- DSH `0.2.2-rc.1`; the gateway touches private host APIs (`ctx.get('sessionQuery')`
  and friends), so a dsh upgrade may break it.
- 27 tests, no network, fake host services — green on Node 20 and 24 in CI.
- Installed from a clean profile and from the registry: `/__gw/health` 200,
  `/m/` 401 → 200 after login, `/m/api/sessions` returns real data.

## Known limits

- One user, one host, one shared token — no account model.
- No push notifications: a phone-origin approval waits up to 15 minutes, then
  cancels.
- Images in *historical* messages render as `[图片]`; only their existence is
  kept.
- Mermaid is vendored (857 KB brotli) and lazy-loaded on the first diagram.

## Notes

`0.1.0` is the first published version. Before this the plugin was installed
by copying a module file into a profile and hand-editing `cordis.patch.yml`;
the bundle replaces that copy/bump-id/refresh-snapshot ritual with one
`dsh plugin add`.
